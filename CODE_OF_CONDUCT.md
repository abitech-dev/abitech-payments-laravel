# Código de conducta

Este proyecto sigue el
[Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
Se espera un trato respetuoso en los issues, los PR y cualquier otro espacio
del proyecto.

Para reportar una conducta inaceptable, escribe en privado desde
**Security → Report a vulnerability**.
